# Font sources

Downloaded 2026-10-05 from the official Google Fonts service. Both families use the SIL Open Font License 1.1; the complete licenses are included beside these files.

| Local file | Family | Style and supported weight | Subset |
| --- | --- | --- | --- |
| `archivo-latin.woff2` | Archivo | Normal, variable 400–800 | Latin |
| `ibm-plex-mono-latin.woff2` | IBM Plex Mono | Normal, regular 400 | Latin |

The Google Fonts request serves Archivo as a variable font and IBM Plex Mono as separate static weights. Only the regular IBM Plex Mono file is included.

- [Official Google Fonts stylesheet](https://fonts.googleapis.com/css2?family=Archivo:wght@400..800&family=IBM+Plex+Mono:wght@400;500&display=swap)
- [Archivo WOFF2](https://fonts.gstatic.com/s/archivo/v25/k3kPo8UDI-1M0wlSV9XAw6lQkqWY8Q82sLydOxKsv4Rn.woff2)
- [IBM Plex Mono WOFF2](https://fonts.gstatic.com/s/ibmplexmono/v20/-F63fjptAgt5VM-kVkqdyU8n1i8q131nj-o.woff2)
- [Archivo license in the official Google Fonts repository](https://github.com/google/fonts/blob/main/ofl/archivo/OFL.txt)
- [IBM Plex Mono license in the official Google Fonts repository](https://github.com/google/fonts/blob/main/ofl/ibmplexmono/OFL.txt)

The Latin subset covers common Western European text and punctuation. Other scripts should use the site's fallback fonts.
